Outil de traitement des dossiers d'appel d'offres

Mode dropzone : déposez les DCE généraux ou par lot, puis les ACT associés.

Mode d'emploi

  1. Référence BETREC : déposez uniquement des fichiers Excel DCE.
  2. Retours entreprises : déposez uniquement des fichiers Excel ACT.
  3. Lots : le numéro de lot doit être détecté dans le nom ou renseigné à la volée, par exemple lot 01, lot_02, L03.
  4. Téléchargement : quand le fichier résultat est prêt, une fenêtre permet de choisir son nom avant téléchargement.

Déposez le ou les classeurs Excel de référence. Un DCE peut contenir plusieurs lots internes ; aucun numéro n’est alors requis dans son nom.
